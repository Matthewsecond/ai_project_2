## What we are building
A web app (Python / Streamlit, hosted on AWS EC2) for HR companies and staffing agencies. Recruiters upload a CV or describe a candidate, the tool returns AI-ranked matching jobs from the Jobs Intelligence Austria database (110,086 jobs, 335+ portals, all 9 Austrian states). Built on OpenAI text-embedding-3-small + OpenAI Vector Store (cosine similarity). No separate API layer — Streamlit handles everything directly.

## Key technical decisions made
- **No API layer** — Streamlit connects directly to MySQL and OpenAI
- **Embedding model** — OpenAI text-embedding-3-small (multilingual, cost-effective)
- **Vector store** — OpenAI Vector Store (no Pinecone)
- **Primary embedding signal** — job description + title + occupational group; fallback = title + occupational group + ESCO skills
- **ESCO skills** — used for filtering/analytics/standardization, NOT primary matching signal
- **Cosine similarity** — >0.7 strong match, 0.5–0.7 moderate, <0.5 weak
- **Filters** — hard constraints applied before vector search, do not modify score
- **Map** — Folium library for geographic job distribution view
- **Hosting** — AWS EC2
