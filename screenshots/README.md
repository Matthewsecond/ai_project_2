# Screenshots

Screenshots of the running app (Slovakia profile). Real candidate/contact names and
internal CRM status values are masked with grey boxes; everything else is genuine output.

### `search-ai-match.png` — Search → AI match results
Each retrieved job is scored 0–100 with an A/B grade, alongside title, company, location,
salary, source portal, posting date, freshness status, company CRM status and contact.
Per-row actions save a job (or all A/B matches) into the pipeline. *(Contact name and
company CRM status masked.)*

### `pipeline-jobs.png` — Pipeline → Jobs
Saved job matches with AI score + grade and an editable per-row **sales status**
(New / Rejected / Expired), plus candidate, company, location and CSV/Excel export. The
filter bar narrows by status, grade, country, portal, city, saved date, score range and
salary. *(Candidate names masked.)*

### `pipeline-companies.png` — Pipeline → Companies
Saved companies with CRM status and country, filterable and exportable. *(CRM status
values masked.)*
